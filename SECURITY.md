# Security policy

Please do not report active vulnerabilities in public GitHub Issues, pull requests, or discussions.

Use GitHub Private Vulnerability Reporting for this repository when it is enabled. If it is unavailable, contact the repository owner privately through the GitHub profile and include only the minimum reproducible details. Do not include credentials or live exploit data in an ordinary issue.

The supported security line is the latest tagged release. Development builds may contain unreleased changes and are not guaranteed to be supported.

OpenMaintainer is intentionally conservative, but no software or provider can guarantee safety. Please disclose webhook, credential, permission, prompt-injection, data exposure, and dependency issues responsibly. We will acknowledge reports when practical; there is no guaranteed response SLA.
