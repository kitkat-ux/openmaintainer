# Roadmap

There are no promised dates. Priorities may change with maintainer and user feedback.

## 0.1

PR review, issue triage, duplicate detection, Markdown release notes, CLI, GitHub App, provider abstraction, mock demo, and self-hosting foundations.

## 0.2

Additional provider adapters, improved diff chunking, review customization, and optional GitHub Checks output.

## 0.3

Optional maintainer dashboard, repository analytics, and a small plugin API.

## 1.0

Stable configuration and provider APIs, migration guarantees, and broader production deployment guidance.

Good contributor-sized work includes a new provider adapter, output formatter, SQLite storage adapter, similarity improvements, validation refinements, and documentation internationalization.
